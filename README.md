# 🍽️ Zomato Data Analysis – Excel Dashboard

## 📌 Project Overview
This project focuses on customer and order analysis for Zomato using Microsoft Excel.

The goal is to understand customer behavior, ordering patterns, revenue indicators, and customer value through a fully interactive Excel dashboard.

The Excel file includes:
- Raw and cleaned Zomato customer data
- Pivot tables for analysis
- Interactive dashboard with slicers and charts

## 🗂️ Dataset Description

The dataset contains customer-level order information with the following fields:

- Customer_ID – Unique customer identifier
- Order_Date – Date of order
- Gender, Age, Age_Group – Customer demographics
- City – Customer location
- Membership_Type – Gold / Pro / Regular
- Total_Orders – Number of orders placed
- Average_Order_Value – Average spend per order
- Customer_Rating – Customer feedback rating
- Preferred_Cuisine – Favorite food category
- Payment_Mode – UPI, Credit Card, Debit Card, etc.
- Customer_Segment – Low / Medium / High value customers
- Calculated_CLV – Customer Lifetime Value
